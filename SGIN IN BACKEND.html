This is my first authentication project: a sign-up and sign-in system connected to a real backend using Supabase. Users can create an account, log in securely, and access a protected page, while Supabase handles the database, password hashing, and sessions behind the scenes.

The Problem

Most of my earlier projects were front-end only, so there was no way to store users or protect any page. Anyone could open any page, and nothing was saved once the browser was closed.

I wanted to learn how real websites handle accounts: where user data lives, how passwords are kept safe, and how the site knows who is logged in.

The Solution

I connected the front-end to Supabase as a backend, using its database and authentication service to manage users instead of building a server from scratch.

The system includes a sign-up form, a login form with validation and error messages, and session handling that keeps the user logged in and redirects them away from protected pages when they are not.

This project taught me the full flow between a front-end, an API, and a database, and it is the base I will use for my next projects.

Heads up: the demo may not work

This project runs on Supabase's free plan, which automatically pauses a database after about a week of inactivity. If nobody has used it recently, sign-up and login will fail until the project is restored.

If that happens, please watch the demo video in the gallery below to see the login working.
